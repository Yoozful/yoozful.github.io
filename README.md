# Yoozful developer website

Static GitHub Pages website. No build step or external runtime dependencies.

- Homepage: `index.html`
- Responsive styles: `style.css`
- Korean/English switch: `site.js` (browser language initially; preference saved locally)
- Approved Yoozful wordmark: `assets/yoozful.svg`
- Original advertising verification: `app-ads.txt` (unchanged)

Local preview: serve this directory with a static HTTP server.
GitHub Pages: deploy the repository root from the main branch.

App descriptions and support links were checked against current local app sources and the public Touch 25 listing on 2026-11-25.
Touch 25 uses its existing public Play listing. Other apps are marked in testing; no general download availability is claimed.
Screens are representative app captures and may differ from later releases.

No custom domain has been selected or configured. Do not add CNAME until domain ownership and DNS are ready.
